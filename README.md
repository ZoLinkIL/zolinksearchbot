# בוט חיפוש מוצרים בטלגרם

בוט שמאפשר לך להעלות מוצרים (תמונה + קישור), ולמשתמשים לחפש אותם
לפי שם מותג ("חפש לי נייקי") או לפי שליחת תמונה דומה.

## שלב 1: יצירת הבוט בטלגרם

1. פתח שיחה עם [@BotFather](https://t.me/BotFather) בטלגרם.
2. שלח `/newbot` ועקוב אחר ההוראות (שם + username).
3. תקבל **טוקן** בפורמט כזה: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`. שמור אותו.
4. כדי לדעת מה ה-ID שלך (בשביל ADMIN_IDS) — פתח שיחה עם [@userinfobot](https://t.me/userinfobot) והוא יגיד לך.

## שלב 2: הרצה מקומית (לבדיקה)

```bash
pip install -r requirements.txt
export BOT_TOKEN="הטוקן_שקיבלת_מ-BotFather"
export ADMIN_IDS="123456789"   # ה-ID שלך, אפשר כמה מופרדים בפסיק
export CATALOG_GROUP_ID="-1001234567890"   # אופציונלי - רק אם יש קבוצת העלאה נפרדת
export CATALOG_DIR="."   # אופציונלי - איפה לשמור את הקטלוג (ראה "אחסון קבוע" למטה)
python bot.py
```

הבוט ירוץ כל עוד המחשב שלך פתוח והתהליך רץ (polling).

## שלב 3: הוספת מוצרים

יש שתי דרכים (אפשר להשתמש בשתיהן ביחד):

### א. הודעה פרטית לבוט (רק אדמין)

שלח לבוט **תמונה** עם כיתוב (caption) בפורמט הזה:

```
מותג: נייקי P-6000
פרטים:
מידה 40-45
צבע שחור
מחיר: 199 ש"ח
קישור: https://example.com/product123
```

כל שורה תחת "פרטים" הופכת לנקודה נפרדת בתוצאה (✅). שורת "מחיר" אופציונלית.

**כמה תמונות לאותו מוצר?** אפשר לבחור כמה תמונות ביחד ולשלוח אותן כ"אלבום" (Telegram מציג אותן כתמונת-גריד אחת בזמן השליחה) עם כיתוב אחד. כולן יישמרו תחת אותו מוצר, ויוצגו יחד כאלבום כשמישהו יבקש את המוצר הזה. אין הגבלה מעשית מלבד המגבלה של טלגרם עצמו (עד 10 תמונות באלבום אחד).

### ב. קבוצה נפרדת ל"העלאת מוצרים"

אם נוח לך שכמה אנשים יעלו מוצרים, או שתרצה סדר עבודה נפרד — צור קבוצת
טלגרם ייעודית, הוסף אליה את הבוט, ואז כל תמונה עם כיתוב באותו פורמט
שתישלח **בקבוצה הזו** תיכנס אוטומטית לקטלוג (לא משנה מי שלח אותה — כל
מי שנמצא בקבוצה נחשב מורשה, אז שים בה רק אנשים שאתה סומך עליהם).

**איך להגדיר:**
1. צור קבוצה חדשה בטלגרם, והוסף אליה את הבוט.
2. **חשוב:** כדי שהבוט יראה כיתובים של תמונות בקבוצה, צריך לכבות אצלו
   את "Privacy Mode": פתח שיחה עם @BotFather → `/mybots` → תבחר את
   הבוט → `Bot Settings` → `Group Privacy` → `Turn off`.
   (לחלופין: תעשה את הבוט **אדמין** בקבוצה — זה גם עוקף את ה-Privacy Mode).
3. שלח בקבוצה `/groupid` — הבוט יחזיר לך מספר (למשל `-1001234567890`).
4. הוסף את המספר הזה כמשתנה סביבה `CATALOG_GROUP_ID` (ראה שלב 5).

חיפוש ("חפש לי...", שליחת תמונה) ימשיך לעבוד כרגיל בכל מקום אחר —
בצ'אט פרטי עם הבוט, או בקבוצות אחרות — חוץ מקבוצת ההעלאה עצמה.

## שלב 4: שימוש (מכל משתמש)

- `חפש לי נייקי` — חיפוש **מטושטש (fuzzy)** לפי מותג, סובלני לטעויות הקלדה קטנות (למשל "ניקי" או "נייקיי" עדיין ימצאו "נייקי"). אם יש תוצאה אחת, מקבלים תמונה + פרטים מלאים + פוטר קבוע. אם יש כמה תוצאות, מקבלים **רשת תמונות ממוספרת** (2x2) עם כפתורים — לוחצים על מספר ורואים את הפרטים המלאים של אותו מוצר. אם יש יותר מ-4 תוצאות, מופיע גם כפתור "עוד דגמים / צבעים 🔍" לדף הבא.
- **גם בלי "חפש לי"** — פשוט לכתוב שם מותג (עד 3 מילים, למשל רק "נייקי") עובד באותה צורה, כולל הטולרנטיות לטעויות הקלדה. ההבדל היחיד: אם אין התאמה, הבוט לא מגיב כלום (כדי לא "לתקוע" הודעת שגיאה על כל הודעת צ'אט סתמית שלא הייתה כוונתה בכלל לחפש). זה לא פעיל בקבוצת ההעלאה עצמה (שם טקסט חופשי הוא לרוב שיחה בין אדמינים).
- `קטלוג` (או `/catalog`) — דפדוף בכל המוצרים בקטלוג, באותה רשת ממוספרת עם דפדוף.
- שליחת תמונה — אם חיפוש לפי תמונה **פעיל** (ברירת מחדל), הבוט ישווה אותה לתמונות בקטלוג ויחזיר תמונה+פרטים מלאים של ההתאמה הטובה ביותר. אם הוא **כבוי** (`ENABLE_IMAGE_SEARCH=false`), הבוט לא מנסה להתאים בכלל — הוא מודיע למשתמש ומעביר את הבקשה אליך (ראה "קבוצת התראות לאדמין" למטה).
- `/list` — (אדמין בלבד) רשימת כל המוצרים בקטלוג (מזהה, מותג, מחיר, קישור).
- `/edit <מזהה>` — (אדמין בלבד) מתחיל עריכת מוצר קיים. אחרי הפקודה שולחים תמונה (או כמה תמונות כאלבום) עם כיתוב באותו פורמט — שדה שמשאירים ריק נשאר כמו שהיה, ורק מה שכותבים מחדש מתעדכן. התמונות שנשלחות תמיד **מחליפות** את כל התמונות הישנות של המוצר. לביטול: `/canceledit`.
- `/delete <מזהה>` — (אדמין בלבד) מחיקת מוצר.

## קבוצת התראות לאדמין

אפשר להקים קבוצה נפרדת (רק אתה + הבוט) שאליה יישלחו התראות בכל פעם
שמשתמש **לא מצא** מה שחיפש — כדי שתוכל לפנות אליו ישירות:

- חיפוש טקסט ("חפש לי X") בלי תוצאות בקטלוג.
- שליחת תמונה כשחיפוש לפי תמונה כבוי (`ENABLE_IMAGE_SEARCH=false`) — הבוט מעביר את התמונה עצמה לקבוצה.
- שליחת תמונה כשחיפוש לפי תמונה פעיל אבל לא נמצאה התאמה מספיק טובה.

**איך להגדיר:**
1. צור קבוצת טלגרם חדשה, הוסף אליה את הבוט (לא צריך הרשאות אדמין - הבוט רק שולח הודעות, לא קורא אותן).
2. שלח בקבוצה `/groupid` וקבל את המספר שלה.
3. הוסף משתנה סביבה `NOTIFY_GROUP_ID` עם המספר הזה.

בלי `NOTIFY_GROUP_ID` מוגדר, שום התראה לא נשלחת (ברירת מחדל).

## כיבוי זמני של חיפוש לפי תמונה

כדי לכבות את חיפוש התמונה (למשל אם ה-perceptual hashing לא מספיק
מדויק כרגע), הוסף משתנה סביבה:

```
ENABLE_IMAGE_SEARCH=false
```

כשזה כבוי, כל תמונה שנשלחת (שלא כחלק מהוספה/עריכה ע"י אדמין) מקבלת
הודעה ידידותית למשתמש, ומועברת אוטומטית לקבוצת ההתראות (אם הוגדרה)
כדי שתוכל לטפל בפנייה ידנית. כדי להחזיר את זה מופעל, פשוט תמחק את
המשתנה או תשנה אותו ל-`true`.

## שלב 5: העלאה לאחסון קבוע (24/7)

הבוט צריך לרוץ תמיד ברקע כדי לענות בזמן אמת. שתי אפשרויות מומלצות:

### Railway (הכי פשוט)

1. העלה את התיקייה הזו ל-repo חדש ב-GitHub.
2. היכנס ל-[railway.app](https://railway.app), התחבר עם GitHub, ותבחר "Deploy from GitHub repo".
3. ב-Settings → Variables, הוסף:
   - `BOT_TOKEN` = הטוקן שלך
   - `ADMIN_IDS` = ה-ID שלך
   - `CATALOG_GROUP_ID` = מזהה קבוצת ההעלאה (אופציונלי — רק אם הגדרת קבוצה נפרדת, שלב 3ב׳ למעלה)
   - `CATALOG_DIR` = `/data` (**חשוב מאוד** — בלי זה, כל Redeploy ימחק את הקטלוג! ראה "אחסון קבוע" למטה)
   - `NOTIFY_GROUP_ID` = מזהה קבוצת ההתראות (אופציונלי — ראה "קבוצת התראות לאדמין" למעלה)
   - `ENABLE_IMAGE_SEARCH` = `false` (אופציונלי — לכיבוי זמני של חיפוש תמונה, ראה למעלה)
4. Railway יריץ אוטומטית `python bot.py` (וודא ש-Start Command מוגדר כך, או הוסף `Procfile` עם `worker: python bot.py`).

### Render

דומה ל-Railway: "New Background Worker" → מחברים ל-GitHub repo → מגדירים משתני סביבה `BOT_TOKEN`, `ADMIN_IDS` ו-`CATALOG_DIR` → Build Command: `pip install -r requirements.txt` → Start Command: `python bot.py`. ב-Render התיקייה הקבועה נוצרת תחת "Disks" (במקום "Volumes").

## אחסון קבוע — קריטי!

כברירת מחדל, קבצי הקטלוג (`catalog.json` + `catalog_images/`) נשמרים
על הדיסק **הזמני** של השרת. ב-Railway/Render, הדיסק הזה מתאפס בכל
**Redeploy** — כלומר כל מוצר שהוספת ייעלם.

כדי למנוע את זה, צריך דיסק **קבוע** (Volume):

1. ב-Railway: לך לשירות שמריץ את `bot.py` → Settings → Volumes → New Volume. תן לו Mount Path קבוע, למשל `/data`.
2. הוסף משתנה סביבה `CATALOG_DIR=/data` (ראה שלב 5 למעלה) — הבוט כבר תומך בזה, הוא ישמור וישחזר את הקטלוג מהתיקייה הזו במקום מהתיקייה הזמנית של הקוד.
3. עשה Redeploy אחד אחרון. מרגע זה, מוצרים שתוסיף יישרדו כל Redeploy עתידי.

בלי `CATALOG_DIR` מוגדר, הבוט ימשיך לעבוד אבל יאבד את הקטלוג בכל דיפלוי חדש — לכמות בדיקות קטנה זה בסדר, אבל לשימוש אמיתי חובה להגדיר Volume.

## התאמה אישית לרשת הדפדוף

- רגישות החיפוש המטושטש (fuzzy) נשלטת ע"י `FUZZY_MATCH_THRESHOLD` (0-100, ברירת מחדל 80) בתחילת `bot.py`. מספר נמוך יותר = יותר סובלני לטעויות הקלדה, אבל גם יותר סיכוי להתאמות שגויות; מספר גבוה יותר = מדויק יותר אבל פחות סלחני.
- כמה שניות ממתין הבוט לפני שהוא מעבד אלבום תמונות שהתחיל להישלח, נשלט ע"י `MEDIA_GROUP_DEBOUNCE_SECONDS` (ברירת מחדל 1.5 שניות) בתחילת `bot.py`. אם אלבומים גדולים (הרבה תמונות) לפעמים "נחתכים" ונשמרים כשני מוצרים נפרדים, אפשר להעלות את המספר הזה מעט.
- כמות המוצרים בכל עמוד (ברירת מחדל 4, פריסת 2x2) נשלטת ע"י `GRID_PAGE_SIZE` בתחילת `bot.py`.
- גודל התגית האדומה עם המספר וגודל הפונט נשלטים ע"י המשתנים `cx, cy, r` וגודל הפונט בתוך `build_grid_image()`.
- טקסט ההודעה שמלווה את הרשת ("🔍 מצאתי כמה דגמים...") נמצא ב-`send_grid_page()`.
- הפונט לתגיות המספרים האדומות (`assets/DejaVuSans-Bold.ttf`) מגיע **בתוך** תיקיית הפרויקט בכוונה, כדי שזה יעבוד גם בשרתים (כמו Railway) שלא בהכרח מותקנים עליהם פונטים - אל תמחק את תיקיית `assets/`.

## אמינות ודיבוג

הבוט כולל error handler גלובלי: אם קורה חריג בעיבוד הודעה, המשתמש
תמיד יקבל הודעת "קרתה תקלה" (במקום שקט מוחלט), והשגיאה המלאה
(traceback) נכתבת ללוגים של השרת — שם אפשר לאבחן בדיוק מה נכשל.

## עריכת הפוטר הקבוע

הטקסט הקבוע שמתווסף לכל תוצאה (הסבר הזמנה, קישור לסרטון, יוזרנייםים,
הבהרת אחריות) נמצא במשתנה `RESULT_FOOTER_HTML` בתחילת `bot.py`. אפשר
לערוך אותו שם בכל שלב בלי לגעת בשאר הקוד.

## מבנה הקבצים

```
telegram-product-bot/
├── bot.py               # הקוד הראשי
├── requirements.txt
├── assets/
│   └── DejaVuSans-Bold.ttf   # פונט לתגיות המספרים ברשת הדפדוף - חובה להעלות!
├── catalog.json          # נוצר אוטומטית - מסד הנתונים של המוצרים
└── catalog_images/       # נוצר אוטומטית - התמונות שהועלו
```

**חשוב:** כשאתה מעלה את הפרויקט ל-GitHub/Railway, תוודא שתיקיית `assets/`
עם קובץ הפונט עולה גם היא (לפעמים קבצי `.ttf` נחסמים ע"י `.gitignore`
כלשהו בטעות - בדוק שהיא בפועל ב-repo).
